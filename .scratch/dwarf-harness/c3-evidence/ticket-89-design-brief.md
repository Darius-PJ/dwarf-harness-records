## 3. Public interface, data shapes and errors

Add `internal/core/agents/task_facts_types.go` with the following concrete types (existing `uuid`, `ledger` and standard-library `errors` imports only). These are internal Core package interfaces, not ledger/launcher encodings or a persistent file format. P1/P2/P5/P6 select their exact shape from T89:27-31; value precedents are `internal/core/agents/scoped_types.go:179-217`, `contract/ledger/scoped_authority.go:163-181` and `contract/ledger/scoped_values.go:51-59`.

```go
var ErrTaskFactsStale = errors.New("agents: task facts revision is stale")

type TaskFactsQuery struct {
    AgentID uuid.UUID        // requested current assignee agent; required
    GrantID uuid.UUID        // Agent: selected inspect leaf; owner: zero
    Limit   int
    Cursor  *TaskFactsCursor // nil starts a new current enumeration
}

type TaskFactsCursor struct {
    ColonyID        uuid.UUID
    Actor           string        // owner or agent
    Origin          ledger.Origin // zero for owner; exact bound origin for Agent
    AgentID         uuid.UUID     // exact query target
    GrantID         uuid.UUID     // zero for owner
    ThroughSequence uint64        // whole-commit high-water, not effect sequence
    AfterTaskID     uuid.UUID      // last returned authorized eligible task
}

type TaskFact struct {
    TaskID         uuid.UUID
    Version        int64
    State          string
    Assignment     ledger.Assignment // value copy, including assigning principal
    DescriptionRef ledger.ArtifactRef
    Sequence       uint64
    Readiness      string
    Reason         string
}

type TaskFactCounts struct {
    WaitingReady   int
    WaitingBlocked int
    Active         int
}

type TaskFactsPage struct {
    AgentID         uuid.UUID
    WaitingReady    []TaskFact
    WaitingBlocked  []TaskFact
    Active          []TaskFact
    Counts          TaskFactCounts
    ThroughSequence uint64
    Next            *TaskFactsCursor
}

func (s *Service) ListTaskFacts(ctx context.Context, q TaskFactsQuery) (TaskFactsPage, error)
func (a *Agent) ListTaskFacts(ctx context.Context, q TaskFactsQuery) (TaskFactsPage, error)
```

**Field contract (P1/P2).** Every returned fact is the exact current task ID/version/state and assignment; Assignment.Assignee.AgentID equals the query target. Assignment includes its ID, generation, assignee binding, assigning actor and assigning origin. Both a same-agent claim/assignment and an owner/other-agent delegation are included by this same predicate; neither creator, actor role nor audience creates a second owner. DescriptionRef is `{SourceSequence: original creation effect sequence, SHA256: recorded description digest, Bytes: recorded description size}`, not a body read or permission to read it. No Title field exists in the producer, so none is synthesized: a forbidden task has neither a description reference nor text in this result. Consumers may separately request actual description bytes through the existing authorized artifact entrance. Sources: T89:27,30; `contract/ledger/scoped_values.go:51-59`; `contract/ledger/scoped_authority.go:163-181`; `internal/core/agents/scoped_tasks.go:198-220`; `internal/core/agents/scoped_task_query.go:138-154`; `internal/core/agents/doc.go:129-139`.

Sequence is the most recent **task effect** record, not the last change to readiness; a dependency completion, grant revocation, capacity update or ending may change readiness without changing this task's version/effect sequence. ThroughSequence qualifies the entire page, readiness and totals. Every success has three non-nil slices (empty where appropriate), fresh owned cursor/row values and Counts for all visible eligible tasks of this target at that head, including rows before/after this page. No global/hidden/terminal/unassigned/submitted count is returned. A valid target UUID with no visible eligible tasks, whether registered or unknown, gives that same empty success; do not add a registration-existence query. P1/P2/P3/P5; sources: T89:27-31; `internal/core/agents/scoped_task_query.go:99-154,157-214`; `internal/core/agents/scoped_state.go:112-155`; `internal/core/agents/review_plan.go:214-230`; `internal/core/agents/scoped_query.go:12-34`.

**Refusals (P3/P5/P6).** Preserve lifecycle/context precedence through `scopedQuery`; a nil/unbound Agent returns ErrNotBound, and closed/poisoned/cancelled queries use existing errors. Invalid target UUIDv7, Limit ≤ 0, owner GrantID, malformed cursor (including zero/invalid AfterTaskID or zero ThroughSequence), or cursor scope mismatch returns ErrInvalid. Limit > current MaxLiveTasks returns ErrTooLarge. No usable selected inspect chain returns ErrDenied. After current authorization, a well-shaped, correctly scoped cursor with ThroughSequence != the refreshed committed head returns ErrTaskFactsStale. Underlying authoritative read/reducer errors propagate, including ErrInconsistent/ErrUnavailable where the existing helpers produce them. Every error returns `TaskFactsPage{}`: no partial rows, totals, Next or current marker. Check errors with errors.Is, never message text. Sources: T89:30-35; `internal/core/agents/scoped_task_query.go:17-49,59-98,138-154`; `internal/core/agents/scoped_query.go:12-34`; `internal/core/agents/types.go:11-19,22-68`.

## 5. Pagination, revision and recovery

**Ordering and bounds (P5/P6).** Raw 16-byte TaskID ascending (bytes.Compare), independent of assignment time, readiness, agent directory, clock or map iteration. Every success returns at most Limit rows **in total**, not Limit in each slice; each slice preserves that order. Buckets are separate slices, so their concatenation is not promised to be globally sorted. If an authorized eligible look-ahead exists, Next.AfterTaskID is the largest ID actually returned, and the other Next fields copy this query's current colony, authenticated entrance, target, selected grant and high-water. Otherwise Next=nil. Never use a skipped/hidden/submitted/terminal ID as a cursor or let it create a more-results flag. Counts are all eligible visible tasks at the head and remain identical across an unchanged enumeration; sum(Counts) may exceed the page size. Sources: T89:30-31; `internal/core/agents/scoped_task_query.go:99-136`; `internal/core/agents/scoped_types.go:214-217`.

**Cursor shape (P5).** It is a copied Go value, not a credential or signed bearer token. Validate ColonyID against this store, Actor against owner/agent entrance, Origin against zero for owner or the exact bound Agent origin, AgentID and GrantID against q, plus positive ThroughSequence and valid nonzero AfterTaskID. A malformed/mismatched coordinate is ErrInvalid after the selected-chain precheck; a caller cannot carry an owner cursor into an Agent query or accidentally continue another target/grant/context. Limit may change between pages. Do not look up AfterTaskID to prove existence/visibility, and never reflect an untrusted cursor into Next unless a returned row supplies its last ID. Forging the numbers can only change the caller's traversal coordinate; it cannot skip authorization or reveal hidden metadata. Sources: T89:30-31; `internal/core/agents/doc.go:7-13,106-117`; `internal/core/agents/scoped_task_query.go:65-136`; `internal/core/agents/scoped_query.go:12-34`.

**Revision and restart (P5).** ThroughSequence is `p.through`, the last fully accepted commit's final sequence, not a wall clock, max task sequence, authority version, receipt or Reader checkpoint. A correctly scoped continuation is accepted only at that **same current** high-water, never replayed as an old authorized snapshot. Every later committed group can stale it, including unrelated records; a selected-chain revocation is ErrDenied before any stale response. Restart at an unchanged head permits the same scalar cursor after binding the same principal again. If the head advanced, discard the incomplete accumulated pages and start with Cursor=nil; each new call exposes current facts immediately. Previously completed enumerations are snapshots, not live permits. Consumers need only this typed query and their cursor, not a ledger scan; Service.Open still performs its normal authoritative recovery. Sources: T89:29-31,53; `internal/core/agents/scoped_query.go:12-34`; `internal/core/agents/replay.go:318-470`; `internal/core/agents/doc.go:23-35,323-356`; `docs/DECISIONS.md:3130-3140,3170-3171`.

**Cost/retention limits (P6).** Collection visits the currently retained task map, with existing current-chain/dependency/readiness work, and at most O(T·Limit) ID moves for the existing bounded sorted-insertion pattern; retained page candidates are O(Limit), output metadata O(Limit), and Counts is fixed-size. T is retained current tasks, including terminal dependencies that pruneScoped legitimately keeps; it is not lifetime transitions. Do not claim O(1), scan-free service behavior, constant latency or new workload capacity: cold existing authority/dependency/history lookups can still scan H, and Reader checkpoint validation still reads/hashes its containing prefix. The query itself introduces no lifetime-history enumeration, per-task retained index, cached permission, readiness cache or second LRU. Keep ticket 140's single 256-entry/8-MiB metadata allowance and fallback semantics unchanged. Structural output limits suffice for T89:31; neither the ticket nor this design sets a numerical performance acceptance bound, so D160's acceptance-driver CPU profile/quiet-machine campaign is not triggered. Sources: `internal/core/agents/scoped_task_query.go:99-136`; `internal/core/agents/scoped_plan.go:94-164`; `internal/core/agents/scoped_state.go:112-155`; `internal/core/agents/doc.go:323-356`; `docs/DECISIONS.md:3033-3035,3130-3140,3170-3171,3186-3188`; assignment “Settled” item 4.

## 6. Replay, restart and transition safety

**No second reducer (P1/P7).** The query reads the current map **after** scopedQuery refresh and never folds callbacks, command receipts or raw record fragments itself. Existing complete-group acceptance dispatches F3-10/F3-11/F3-12/F3-13/F3-139 before installation, validates the group, installs all selected projections/book state and advances p.through last. Task facts therefore include the same in-sequence task state as TaskStatus without another authority store. Sources: T89:18,28-29,53; `internal/core/agents/scoped_query.go:12-34`; `internal/core/agents/replay.go:318-470`; `internal/core/agents/scoped_plan.go:68-91`; `internal/core/agents/review_plan.go:196-230`.

**Both task-transition families are mandatory.** F3-11 task_changed and F3-12 approve/fail review_result share one task reading. Request/replacement/reject changes no task version; submitted remains submitted and outside this listing under P2. Approve completes, fail fails, advances that exact task version once, unpins once and updates dependency readiness, without a task_changed. No query change to the frozen decoder/catalogue/group rules or goldens is needed. Use the existing replay, taskAfterReview and loaders; a new F3-11-only listing reducer would be incorrect. Sources: T89:53; `docs/CONTRACTS.md:132-138`; `docs/DECISIONS.md:2749,2768-2785`; `internal/core/agents/doc.go:292-308`; `internal/core/agents/scoped_state.go:112-155`; `internal/core/agents/review_plan.go:196-230`; `internal/core/agents/history_index.go:397-435`.

**Claims/assignment/reassignment.** A task appears under only its current assignee agent, with exact assignment ID/generation/binding and actual task version/effect sequence. Reassignment removes its old agent's membership and clears transient wait/submission state through the existing reducer; it does not copy private state or grants. Same-agent reassignment still updates identity/generation once. Old task-bound grants/callbacks cannot start, complete or relabel that replacement. Revocation changes no recorded task state by itself: revoking the viewer's inspect chain denies/removes disclosure, revoking the assignee's start/turn chain blocks its waiting task, and an already active task stays active until an actual task transition. Sources: T89:29-30; `contract/ledger/doc.go:1907-1932`; `internal/core/agents/doc.go:106-139`; `internal/core/agents/scoped_authority.go:12-79`; `internal/core/agents/scoped_tasks.go:119-220`; `internal/core/agents/scoped_task_query.go:157-290`.

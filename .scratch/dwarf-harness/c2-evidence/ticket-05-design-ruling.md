# Ticket 05 design ruling (advisor AdvisorC2, 2026-10-12)

Ruling on [the design brief](ticket-05-design-brief.md). Where the two differ, this ruling wins. The owner's approval of the design (OG-A) and his answer on how F2 is frozen (OG-B) come before any code reaches `main`.

**Verdict:** approve-with-changes.

The brief is faithful to the approved boundary (RC:278–417, CORE:848–882, D112), ticket 05's four criteria and the 05/06 split; every cited source I read says what the brief claims, and the Git probes support the recipe. All 33 choices are accepted, nine of them with modifications; none is rejected. One major change: scratch removal (closure retry and Open's orphan sweep) must be Core-owned and junction-safe, never `git worktree remove --force` on an unverified directory, because Git traverses junctions (G1-R5) and its removal behaviour with one present is unverified. Owner gates: OG-A (design approval before code) and OG-B (F2 staging and record-free code before the freeze) are confirmed; the F2-05 freeze is a third, later owner question; P13, P21 and P23 need no separate question and belong in OG-A's summary. On question 4: a record-free S1 on `main` before the F2-05 freeze is consistent with RC:271, RC:407, T05:49 ("producer implementation") and D41 (S1 touches no frozen contract, owner decision or dependency), but not with the literal "before C2 implementation" of CORE:844, RC:220 and D112's repeat of it, so the owner resolves it at OG-B; S1 may be built after OG-A but must not reach `main` before OG-B is answered, and option 1 should authorize a one-line clarification of CORE:844/RC:220.

## Notes for the coder

1. Build the three Git environments as explicit functions with a test that asserts the exact variable sets of each (strip every `GIT_*`, including `GIT_CONFIG_PARAMETERS` and `GIT_CONFIG_COUNT/KEY_n/VALUE_n`, in environments 2 and 3; G1-R2's environment is unverified, so `TestControlledEnvironmentIgnoresHostGit` is the proof).
2. Always `--end-of-options` before paths and refs, `-z` on every listing, never parse message text; decide outcomes from exit codes and parsed output (`*GitError` otherwise).
3. Capture engine signature: scratch, baseline tree, reservation, mode. Make the reservation an unexported type only `reserve` can mint, so no code path captures unreserved; ticket 06 adds the K-slot to the same `reserve`.
4. Walk with `filepath.WalkDir`, classify by `DirEntry.Type()` then `Lstat`; treat `ModeIrregular` (junctions, mount points) as `special_file` and `ModeSymlink` as `unsupported_kind`; skip the root `.git` file and the ignored directories from step 5 by exact path bytes; do all of this before any Git call that reads file content.
5. Removal is Core-owned and junction-safe (finding 1); verify in a test that `os.Remove` on a junction removes the link, not the target, before relying on `os.RemoveAll`.
6. Round-trip rule: stream crlf(blob) through the hash without buffering whole blobs; compare per path; do not special-case `\r\r\n`; the tests take expectations from reference Git (`git add -A` + `write-tree` in a separate repository with the same pinned config, fixed identity and dates).
7. Version gate: parse the leading major.minor.patch triple (`2.55.0.windows.3`, later `2.39.5 (Apple Git-154)`), pin the full string, and make `inputs_stale` name pinned and running versions.
8. Marker blob: `hash-object -w --stdin --no-filters`; then `update-ref <ref> <blob> <zero ID>`; on a lost race, read again.
9. `GIT_CONFIG_GLOBAL` points at the empty file `workspaces/empty` (G2-R8 used `NUL`; the empty file is portable); `GIT_CONFIG_NOSYSTEM=1` and `GIT_ATTR_NOSYSTEM=1` in the capture environment, with the pinned system attributes materialized into the private `core.attributesFile`.
10. Materialize inputs through temporary file plus rename and compare every file to the pinned bytes before each capture; a tampered copy is rewritten, never trusted.
11. Windows tests: `syscall.CreateFile` with share mode 0 for unreadable/held-handle cases; `cmd /c "mklink /J ..."` for junctions (G2-R9: `cmd //c` from bash creates nothing); skip the symlink test only when creation fails for privilege, naming it.
12. Keep the capture-inputs decoder backward-compatible across document versions; the document is Core-internal, not a contract, but its digests are replayed forever.
13. No clock in replayable code: event times come from the store's appender; Open's replay and reconciliation read no clock.
14. Note for ticket 06+: loose blobs from observe/refused captures accumulate in the workspace object store; a maintenance policy is later work.
15. C3's CI will need Git ≥ 2.42 on Linux and macOS runners; record the version with V10.

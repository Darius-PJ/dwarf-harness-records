# Ticket 07 design ruling (advisor AdvisorT07, 2026-10-13)

Ruling on the design brief `local://t07-brief.md` (DesignT07; at the ticket's close both land under `.scratch/dwarf-harness/c2-evidence/` as `ticket-07-design-brief.md` and `ticket-07-design-ruling.md`). Where the two differ, this ruling wins. Under D117 this ruling ends the design step: no owner design approval is asked, and the build starts from the brief as modified here. The owner's freeze of F2-07 (OG-F7) comes before the code that writes it. Sources are cited as in the brief: RC = `docs/ROADMAP-CORE.md`, CORE = `docs/DESIGN-CORE-AND-LAUNCHERS.md`, DEC = `docs/DECISIONS.md`, UC = `docs/DESIGN-UNDERCURRENT.md`, LD = `contract/ledger/doc.go`, WD = `internal/core/workspace/doc.go`, T0n = the tickets, RU5/RU6 = tickets 05 and 06's rulings, B6 = ticket 06's brief, BR = the brief (raw line numbers), SUP = `local://t07-code-supplement.md`, G7-n = observation n of `local://t07-git-probes.md`, G7R-n = observation n of `local://t07-git-retry-probe.md`, all at `main` f0d4878.

**Verdict:** approve-with-changes.

The brief is faithful to D22/D23 (DEC:62, :71–76), D70 (DEC:504), the D52 boundary (DEC:340–342; RC:289), ticket 07's three criteria (T07:28–30), B23–B25 as built, the advisor notes from ticket 06, and the two probe records, which support the materialization and retry recipe. All 21 choices are accepted, four of them modified (P2, P7, P9, P14); none is rejected. Two major changes close lifecycle holes the brief leaves open: (1) an observed but unmerged temporary scratch can never be closed under the brief, and its parent can never close while it exists, so a temporary needs an explicit `abandoned` path whose represented tree is its own acknowledged tip; (2) an interrupted turn's temporary with unobserved edits can be neither observed nor abandoned, so `BeginWrite` needs an explicit resume of a named open temporary. The minor changes are a writer index keyed by (context, task scratch), a replay-checkable admission-provenance rule, folding `RepairScratchTip` into Open and pre-use repair, one redundant key dropped, the `changed_paths` presence rule stated as this type's own decoder rule, the B-NEXT amendment of B24, and named S1 tests. P2's binding is within the ticket's gates: nothing is recorded or stored, the service compares two caller-stated IDs exactly as it compares `Closure.ContextID` today, and C3 authenticates later (DEC:1813; RU5 P28).
